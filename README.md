# מה מעשנים היום

אפליקציה למטופלי קנאביס רפואי: כרטיס אישי, המלצות מותאמות, דיווח על קניות ופיד אנונימי של מה שעבד למטופלים אחרים. פיילוט באולטרה פארם.

- **הפעלה מהטלפון, צעד אחר צעד:** [`PILOT_SETUP.md`](PILOT_SETUP.md)
- מסד הנתונים (קובץ אחד להדבקה ב-Supabase): [`supabase/pilot_schema.sql`](supabase/pilot_schema.sql)
- בדיקות: [`test/README.md`](test/README.md)
- מפת הפרויקט וההחלטות: [`AUDIT.md`](AUDIT.md) (סעיף 7 מתאר את גרסת הפיילוט)

## מבנה

| נתיב | מה יש שם |
|---|---|
| `app/` | המסכים: פיד (`/`), כרטיס (`/card`), המלצות (`/reco`), עמוד זן (`/strain`), דיווח (`/report`), יומן (`/journal`), הכרטיס שלי (`/me`) |
| `components/` | מצב האפליקציה, ניווט, כניסה, כרטיס פיד, תמונות, חיפוש זן |
| `lib/engine/engine.mjs` | מנוע ההמלצות. עותק זהה נמצא ב-`reco-engine/engine/` |
| `lib/api.js`, `lib/config.js` | הקריאות לשרת וכתובת הפרויקט |
| `supabase/pilot_schema.sql` | טבלאות ופונקציות. הדפדפן לא נוגע בטבלאות, רק קורא לפונקציות |
| `test/` | בדיקות מנוע, בדיקות שרת, ובדיקה מקצה לקצה בדפדפן בגודל טלפון |

Next.js 14 בייצוא סטטי (`npm run build` יוצר את `out/`). אין שרת משלנו: הדפדפן מדבר ישירות עם פונקציות במסד הנתונים.

הקטלוג עצמו לא נמצא בריפו הזה. הוא נטען למסד הנתונים מתוך `reco-engine` (ריפו פרטי) ונקרא רק על ידי מטופל מחובר.
